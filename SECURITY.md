# Security

The latest release is the supported line. We prioritize avoiding silent audio loss, unintended tab access, remote execution, and data transmission.

Do not put passwords, authentication tokens, private URLs, recordings, or exploit payloads in a public issue. Use GitHub's private vulnerability reporting option on the repository's Security tab if available. Otherwise open a minimal issue requesting a private maintainer contact, without disclosing the exploit.

Bug reports should include the browser/version, extension version, reproduction steps, expected/actual behavior, and whether the player uses native or tab-audio mode. Reduce a problem to a local fixture where possible. Dependencies used for testing and packaging are development dependencies; the extension has no third-party runtime dependency.
