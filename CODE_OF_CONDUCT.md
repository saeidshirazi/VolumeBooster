# Community conduct

Be respectful and specific. Welcome contributors with different backgrounds and experience. Discuss the code and observable behavior without personal attacks. Harassment, discrimination, threats, spam, and publishing another person's private information are not acceptable.

Maintainers may edit/remove harmful content and restrict participation to keep the project useful and safe. Report non-sensitive conduct concerns to the maintainers through GitHub; request a private channel before sharing personal information. Apply the same standards in issues, pull requests, reviews, and project discussions.
